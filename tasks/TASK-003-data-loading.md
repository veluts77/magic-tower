# TASK-003 — JSON Data Loading

## Goal

Реализовать загрузку игровых данных из JSON-файлов.
Это фундамент для всего контента: этажи, комнаты, объекты, заклинания
и духи будут описываться в JSON-файлах, а не в коде.

## Design Context

Игра строится на принципе data-driven дизайна.
Все игровые сущности описываются в JSON-файлах в папке `assets/data/`.

Модуль `domain` определяет структуру данных (DTO-классы)
и интерфейсы для доступа к данным, но не знает, откуда они приходят.
Модуль `engine` реализует загрузку, используя возможности libGDX.

Это разделение позволяет:
- тестировать доменную логику без файловой системы;
- менять способ загрузки без изменения домена;
- агенту, работающему над доменом, не знать о libGDX.

На данном этапе мы загружаем только структуру этажей и комнат.
Заклинания, духи и артефакты будут добавлены в будущих задачах.

## Scope

Входит в задачу:

1. Создать структуру папок `assets/data/` с подпапками
   для разных типов данных (этажи, комнаты и т.д.).

2. Определить в модуле `domain` DTO-классы для описания этажа и комнаты.
   Этаж содержит: идентификатор, отображаемое имя, список идентификаторов комнат.
   Комната содержит: идентификатор, отображаемое имя, список объектов.
   Объект комнаты содержит: идентификатор, отображаемое имя, тип.
   Не нужно создавать сложные иерархии наследования.
   Достаточно простых классов с полями.

3. Определить в модуле `domain` интерфейс загрузчика данных.
   Интерфейс должен позволять загрузить определение этажа по его идентификатору.
   Интерфейс не должен ссылаться на libGDX или файловую систему.

4. Реализовать в модуле `engine` загрузчик, который реализует
   доменный интерфейс и читает JSON-файлы через средства libGDX.

5. Создать один тестовый JSON-файл с описанием этажа.
   Этаж должен содержать 2–3 комнаты, в каждой комнате 1–2 объекта.
   Это нужно для проверки, что загрузка работает.

6. Добавить в главный класс игры вызов загрузчика при старте,
   который загружает тестовый этаж и выводит в лог
   имя этажа и количество загруженных комнат.
   Это временная проверка, не часть игровой логики.

Не входит в задачу:

- Рендеринг комнат или объектов.
- Игровая логика: действия, прогрессия, загадки, состояние игрока.
- Загрузка заклинаний, духов, артефактов.
- Полноценная обработка ошибок (достаточно базовой: файл не найден → лог и исключение).
- Кэширование, пул объектов, асинхронная загрузка.
- Валидация данных сверх проверки существования файла.
- Создание отдельных классов-обёрток для строковых идентификаторов.

## Module Placement

- DTO-классы → модуль `domain`, пакет `tower.domain.data`.
- Интерфейс загрузчика → модуль `domain`, пакет `tower.domain.service`.
- Реализация загрузчика → модуль `engine`, пакет `tower.engine.data`.
- Тестовые JSON-файлы → `assets/data/floors/`.
- Вызов загрузчика для проверки → модуль `engine`, в главном классе игры.

## Constraints

- Модуль `domain` не должен содержать импортов из `com.badlogicgames.*`.
- Модуль `domain` не должен содержать импортов `Gdx.*`.
- Не добавлять новые внешние зависимости.
  Для парсинга JSON использовать встроенный `com.badlogic.gdx.utils.Json`.
- Не создавать сложные абстракции.
  Достаточно одного интерфейса и одной реализации.
- Идентификаторы сущностей на данном этапе — простые строки.
- DTO-классы должны быть совместимы с `com.badlogic.gdx.utils.Json`
  (публичные поля или геттеры/сеттеры, конструктор без аргументов).

## Acceptance Criteria

1. В `assets/data/floors/` существует хотя бы один JSON-файл.
2. Модуль `domain` содержит DTO-классы для этажа, комнаты и объекта.
3. Модуль `domain` содержит интерфейс загрузчика данных.
4. Модуль `engine` содержит реализацию загрузчика.
5. При запуске приложения тестовый этаж загружается,
   и в лог выводится имя этажа и количество комнат.
6. В модуле `domain` нет импортов из `com.badlogicgames`.
7. `./gradlew build` завершается успешно.

## Verification

```bash
./gradlew build
./gradlew desktop:run
```

При запуске в консоли должна появиться строка лога
с информацией о загруженном этаже.

Проверка, что домен не зависит от libGDX:

```bash
grep -r "com.badlogicgames" domain/src/
grep -r "Gdx" domain/src/
```

Обе команды должны вернуть пустой результат.
