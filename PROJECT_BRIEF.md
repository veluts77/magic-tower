# Project Brief

## Working Title

Tower Game

## Genre

Meditative adventure / puzzle exploration game.

## Core Fantasy

Игрок управляет волшебником, который попал в башню и должен подниматься всё выше.
По мере подъёма он осваивает новые заклинания, находит артефакты, изучает духов
и постепенно становится более опытным волшебником.

## Main Reference

Игра вдохновлена `Heavy on the Magick` для ZX Spectrum, но не копирует её напрямую.

Из референса берём:

- атмосферу магического исследования;
- ощущение уязвимого, но обучающегося волшебника;
- использование заклинаний как инструмента решения задач;
- неспешный темп;
- взаимодействие с объектами и сущностями.

Но мы делаем более современную структуру:

- понятные этажи башни;
- прогрессия через освоение этажа;
- без текстового парсера;
- без большого инвентаря;
- без агрессивных монстров, которые постоянно охотятся за игроком.

## Game Feel

Темп игры:

- медленный;
- созерцательный;
- без экшен-давления;
- с акцентом на исследование и эксперимент.

Игрок должен чувствовать, что башня — это не арена, а загадочное место,
которое нужно понять.

## Visual Style

Выбран визуальный подход:

- оригинальный подход, близкий к старым приключенческим играм;
- каждая комната представлена как отдельный экран;
- персонаж и объекты могут быть крупными спрайтами;
- изометрия пока не используется;
- на начальном этапе используются placeholder-graphics;
- финальная графика может частично генерироваться или дорабатываться через AI.

Важно:

- не делать изометрию на данном этапе;
- не делать сложную физику;
- не делать полноценный платформер;
- не делать сложную покадровую анимацию без необходимости.

## Technology Stack

- Language: Java
- JVM version: Java 21 preferred
- Framework: libGDX
- Build tool: Gradle
- Target platform: Desktop only
- Data format: JSON
- Architecture style: simple data-driven architecture
- No Android, no iOS, no WebGL for now.

## Current Goal

Создать технический фундамент проекта:

1. проект собирается через Gradle;
2. запускается пустое окно приложения;
3. структура проекта готова к будущему добавлению игровых экранов;
4. есть документация для следующих задач.

## Non-Goals

На данном этапе явно не делаем:

- реальный геймплей;
- комнаты;
- заклинания;
- инвентарь;
- сохранение;
- боевую систему;
- процедурную генерацию;
- изометрию;
- сложный UI;
- интеграцию с AI-генерацией изображений;
- мобильные платформы;
- серверную часть.
